# Asset permissions

Jelly Hop adapts [Jelly Baby by scottstts](https://github.com/scottstts/Jelly-Baby).
The checkout contains no root LICENSE, COPYING, or NOTICE file. The upstream
GitHub license endpoint returned 404 during this work. No explicit license or
provenance statement was found for the character/reference meshes, EXR room,
wood maps, screenshot, or favicon. Public availability is not a redistribution
grant. Obtain permission or confirm their original licenses before distributing
the game publicly; no license has been invented for these assets.

The character mesh, physics references, face, environment, and wood assets stay
in the repository. The Android launcher uses the existing favicon silhouette.
Contact audio is the original procedural Web Audio implementation.

Runtime dependency license texts are preserved in
`public/THIRD_PARTY_NOTICES.txt`, which Vite copies into the offline APK assets.
These dependency licenses do not resolve upstream artwork/code permissions.
No publishing or release signing is configured.
